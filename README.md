## 共享和独享到底差什么

奈飞的 Premium 档支持 5 个独立子账户，平台把 5 个“车位”拆开租给 5 个人分摊订阅费。账号所有者叫“车主”，你买到的是其中一个子账户。每个车位有独立的 PIN、独立的观影记录和推荐列表，互相看不到对方看了什么。

差别集中在这几处：

**能不能上电视。** 官网写得很直白：“现在共享账号已不能在电视上使用，仅限独享可以。”这条是所有限制里后果最严重的一条，因为它决定了你买完之后在哪个屏幕上用。手机、平板、电脑没问题，电视和 Apple TV 不行。

**能不能动设置。** 共享号登录后不要改 PIN 之外的东西，密码、付款方式都不能碰。官网原文：“登录后请勿修改任何PIN等其他设置，违者取消资格。”多次触发验证之后，平台不再提供售后。独享号是你一个人的，不受这条约束。

**画质。** 共享和独享都挂在 Premium 档下，4K 是 Premium 的专属权益，Standard 档最高 1080p，这点奈飞官方帮助页写得很清楚。但共享号能不能真的看出 4K，还取决于你的设备、你的代理和当时的网络，账号本身只是其中一个条件。
